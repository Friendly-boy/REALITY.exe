# REALITY.exe — 복도 07

중력과 공간이 뒤틀린 약 700m의 복도를 탐험하는 1인칭 브라우저 게임입니다. 구역은 학교 별관, 13층 아파트, 지하 설비 통로로 바뀌며, 각 장소에 맞는 사물과 색으로 구분됩니다. 이동한 주변 구간만 생성해 렉을 줄입니다.

## 임무

1. 학교 구역에서 신호 중계기 세 개를 복구합니다.
2. 관찰자를 피해 깊은 구역에서 기억 기록 다섯 개를 회수합니다.
3. 신호가 연 출구를 찾아 탈출합니다.

세 번째 중계기를 켜면 맵 바깥 창문 너머의 거대한 눈이 깨어납니다. 눈을 감으면 다음 관측창으로 빠르게 이동하고, 눈을 뜨면 움직임을 감시합니다. 눈이 감긴 동안 이동하고, 눈이 떠진 동안은 멈추거나 `C` 은신 자세로 천천히 움직이세요. 달리면 감지도가 더 빨리 차며, 가득 차면 피해를 입습니다. `G` 중력 파동은 잠시 천장으로 떠오르게 하고 감지 흔적을 낮춥니다. 넓은 안정 구역에서는 감지되지 않고 체력도 회복됩니다. 임무 진행과 체크포인트는 자동 저장됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W A S D` | 보는 방향 기준 이동 |
| 마우스 | 시점 조작 |
| `Shift` | 달리기 (스태미나 소모) |
| `C` | 은신 자세 켜기/끄기 (느리게 이동, 감지 감소) |
| `G` | 중력 파동 (천장으로 이동, 감지 흔적 감소) |
| `E` | 중계기 복구, 기억 회수, 출구 통과 |
| `P` 또는 `Esc` | 일시정지 |
| 화면 우측 상단 | 음악 켜기/끄기, 전체 화면 |

점프는 없습니다. 중력 파동의 짧은 천장 이동을 회피 수단으로 사용하세요. 휴대폰이나 태블릿에서는 왼쪽 조이스틱으로 이동하고, 오른쪽 화면을 드래그해 둘러보세요. `RUN`을 누른 채 이동하면 달리고, `HIDE`를 눌러 은신 자세를 전환할 수 있습니다.

탐사 중 Web Audio로 생성한 앰비언트 음악과 효과음이 재생됩니다. 음악은 우측 상단 버튼으로 끌 수 있습니다. 브라우저 오디오 정책 때문에 첫 조작 뒤에 소리가 시작됩니다.
