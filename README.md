# REALITY.exe — 복도 07

중력과 공간이 뒤틀린 약 700m의 복도를 탐험하는 1인칭 브라우저 게임입니다. 구역은 학교 별관, 13층 아파트, 지하 설비 통로로 바뀌며, 각 장소에 맞는 사물과 색으로 구분됩니다. 이동한 주변 구간만 생성해 렉을 줄입니다.

## 임무

1. 학교 구역에서 신호 중계기 세 개를 복구합니다.
2. 관찰자를 피해 깊은 구역에서 기억 기록 다섯 개를 회수합니다.
3. 신호가 연 출구를 찾아 탈출합니다.

세 번째 중계기를 켜면 외눈 형태의 관찰자가 깨어나 플레이어를 따라옵니다. 관찰자를 오래 바라보면 시선 노출이 쌓여 피해를 입으므로 고개를 돌려야 합니다. `G` 중력 파동은 잠시 천장으로 떠오르게 하고, 가까운 관찰자를 기절시켜 시선 노출도 낮춥니다. 넓은 안정 구역에는 관찰자가 들어오지 못하며 체력도 회복됩니다. 임무 진행과 체크포인트는 자동 저장됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W A S D` | 보는 방향 기준 이동 |
| 마우스 | 시점 조작 |
| `Shift` | 달리기 (스태미나 소모) |
| `G` | 중력 파동 (천장으로 이동, 관찰자 교란) |
| `E` | 중계기 복구, 기억 회수, 출구 통과 |
| `P` 또는 `Esc` | 일시정지 |
| 화면 우측 상단 | 음악 켜기/끄기, 전체 화면 |

점프는 없습니다. 중력 파동의 짧은 천장 이동을 회피 수단으로 사용하세요. 휴대폰이나 태블릿에서는 왼쪽 조이스틱으로 이동하고, 오른쪽 화면을 드래그해 둘러보세요. `RUN`을 누른 채 이동하면 달립니다.

탐사 중 Web Audio로 생성한 앰비언트 음악과 효과음이 재생됩니다. 음악은 우측 상단 버튼으로 끌 수 있습니다. 브라우저 오디오 정책 때문에 첫 조작 뒤에 소리가 시작됩니다.

## 실행

`index.html`을 정적 웹 호스트에서 제공해 주세요. Three.js는 unpkg CDN에서 불러오므로 인터넷 연결이 필요합니다. GitHub Pages에서는 저장소의 **Settings → Pages → Deploy from a branch**에서 `main` 브랜치와 `/(root)`를 선택하면 웹에서 플레이할 수 있습니다.

로컬에서는 PowerShell에서 게임 폴더로 이동해 `py -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 여세요.

저사양 기기의 렉을 줄이기 위해 반복 오브젝트를 인스턴싱하고, 주변 구간만 유지하며, 렌더 해상도와 프레임률을 제한합니다. 화면 오른쪽 위에서 현재 FPS를 확인할 수 있습니다.
